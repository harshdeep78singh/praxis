# praxis: Philosophy

CLAUDE.md summarizes this. This file is the source.

1. Clarity is the deliverable. Before action, define intent, size and scope,
   direction, and success criteria. praxis manufactures clarity; execution is
   downstream. This is the core reason praxis exists over plain OpenSpec, which
   assumes you are already clear enough to write a change.

2. One universal loop; the scientific model is a lens, not a cage. The universal
   shape is explore, derive action items, execute, return and build on what
   exists, repeat. The "current truth" is simply what you already know and have
   built in a stream. The controlled-experiment framing (one variable, its
   impact on the truth) is a useful lens where a stream has a crisp truth, not a
   rule imposed where none exists yet.

3. Externalize to protect the mind. You can recall a lot, but as findings
   compound into a large graph, tracking impact strains working memory. praxis
   holds the truth and the impact graph externally, so memory is never the
   bottleneck.

4. Exploration is the main event. The most time-consuming, highest-value, and
   currently uncovered phase is exploration plus action-item derivation. praxis
   makes it rigorous, complete (no silent gaps), reviewable, and value-capturing.

5. Compounding over completion. Every exploration leaves durable residue (a
   mental model, a research note, a script, a decision). Capture is near
   zero-friction, so today's work makes tomorrow's cheaper.

6. The value filter is the gate. Save time, improve quality, innovate, or
   optimize learning, or it is parked or killed. Tool adoption is heavily gated.

7. Prioritize what must be applied. Learning without application is the failure.
   praxis forces prioritization of what gets executed, and forces closure.

8. AI absorbs breadth; the human does the interesting depth. The split is made
   explicit per topic, not left to accident.

9. Messy-first, then crystallize, as separate phases. Play then rigor, taking
   turns, never mixed.

10. Generic spine, pluggable streams. Portable and sovereign. Plain text, git,
    yours, on any machine. OpenSpec is a swappable substrate.
