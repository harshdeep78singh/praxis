# praxis: Value Filter

The gate for everything: tools, techniques, rabbit holes, and AI responses.

## The four axes

A candidate earns its place only if it does at least one of these well:

- Saves time. Removes or shortens repeated effort.
- Improves quality. Raises correctness, depth, or reliability of the output.
- Innovates. Brings a genuinely better or novel approach to the table.
- Optimizes learning or research. Deepens understanding or accelerates it.

## How to apply

1. Name which axis (or axes) the candidate hits, and how, in one line.
2. If it hits none, park it (backlog) or kill it. Do not adopt by default.
3. For tools specifically: log the candidate and its alternatives first (the
   tool-scout pattern), then adopt only after the filter passes. This is the
   anti-sprawl gate.

## Where it also applies

- Responses (Charter principle 8): motion without value gets cut.
- Explorations: every RFC states its intended value axis and a success
  criterion, and records realized value at close. That value ledger tunes future
  prioritization.
